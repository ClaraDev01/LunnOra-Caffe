# ☕ LunnOra Caffè

A responsive landing page for an artisanal coffee shop, featuring a warm and elegant design, popular drinks, brand story and new menu items. Built with HTML, CSS and JavaScript — no libraries used.

![Status](https://img.shields.io/badge/Status-Completed-success?style=for-the-badge)
![Responsive](https://img.shields.io/badge/Fully-Responsive-blue?style=for-the-badge)

<br/>

## 🚀 Live Demo

🔗 https://claradev01.github.io/LunnOra-Caffe/

<br/>

## ✨ Features

- ☕ Elegant hero section presenting the brand
- ⭐ "Populares" section highlighting the 3 most loved drinks
- 📖 "Sobre" section with the brand story and a highlighted quote
- 🆕 "Novidades" section showcasing 4 new drinks
- 🍔 Mobile menu built with pure CSS (checkbox hack)
- 🎞️ Smooth scrolling and fade-in animations on scroll
- 🎨 Consistent design with CSS variables (colors, fonts and transitions)
- 📱 Fully responsive — works on mobile, tablet and desktop
